# Tidy Tabs

Google Sheets / Excel templates and how-tos for US small business owners and
freelancers, auto-published to Blogger (tidytabs.blogspot.com) once a day.

- `posts/ready/` — finished posts, published oldest-first at 6am PT
- `posts/drafts/` — machine drafts (never published directly)
- `templates/` — downloadable .xlsx/.csv, built by `scripts/build-templates.py`
- `images/<post>/` — GPT illustrations (`ai-*.jpg`) and real screenshots
- `.claude/agents/` — content team: researcher → hook-writer → script-writer → designer → publisher
- `docs/style-guide.md` — voice, honesty rules, post structure
- Setup: `docs/blogger-setup.md`, `docs/search-console-setup.md`
